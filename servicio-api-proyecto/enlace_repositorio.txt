DESCRIPCIÓN DE LA ENTREGA:
Este repositorio contiene el código fuente completo del proyecto formativo Barbería Harry Estilos, incluyendo la implementación de los servicios web RESTful (Spring Boot 3, Java 17+, JDBC, MySQL) para el cumplimiento de la evidencia GA7-220501096-AA5-EV03:
- Módulo de Citas (CRUD completo y filtros por barbero)
- Módulo de Catálogo de Servicios (Consulta, creación y actualización)
- Módulo de Barberos (Consulta y registro del equipo)
- Módulo de Clientes (Consulta, creación y actualización)
- Módulo de Autenticación y Registro de Usuarios (Hash SHA-256 + Salt)
- Documentación OpenAPI 3.0 / Swagger UI interactiva integrada
- Colección de pruebas en Postman v2.1.0
