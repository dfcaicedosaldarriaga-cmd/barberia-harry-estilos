UBICACIÓN DE ESTE MÓDULO EN EL REPOSITORIO:
Carpeta "servicio-auth-api" en la raíz del repositorio, hermana del
proyecto principal (WAR JSP/Servlet). Es un módulo Maven Spring Boot
independiente, no integrado al WAR, para no modificar el despliegue
existente.

RELACIÓN CON EL PROYECTO PRINCIPAL:
Este servicio reutiliza literalmente las clases UsuarioDAO, Usuario,
PasswordUtil y RegistroValidator del módulo de sesión del proyecto
principal (GA7-220501096-AA3-EV01/EV02) y opera sobre la misma base de
datos MySQL "barberia_harry_estilos", tabla "usuarios". No se duplican
datos ni se crea un modelo de usuarios paralelo.

ESTADO DE VERSIONAMIENTO:
Código desarrollado en Java 17 + Spring Boot 3.3.4, debidamente
versionado, comentado, y publicado en la rama 'main' del repositorio
remoto compartido del equipo.
